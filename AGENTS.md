## Japanese study notes (`notes/日语学习.md`)

- **Lecture slides** are in `/Users/alant/Documents/Japanese`, one folder per course (e.g. `Pre 2 Genki2 16-18`, `Pre-4 Genki2 22-23`, `Intermediate 1` for Quartet 1). Use them as the source of truth when adding or checking grammar points.
- `/Users/alant/Documents/Japanese/genki-study-resources` and `/Users/alant/Documents/Japanese/quartet-study-resources` are **not** lecture slides. They contain workbook exercises and study material, which are useful clues for which textbook and chapter covers a grammar point (e.g. `genki-study-resources/lessons-3rd/lesson-22/grammar-6` is the ～ば practice for Genki L22). Use them to locate the right lesson, then find the matching lecture slides.
- Many slide PDFs embed Japanese text in fonts that `pdftotext` can't decode, so only the English text comes out. Search the English text (e.g. "conditional", page numbers like "P234") to find the page, then render it with `pdftopng` to read the Japanese.
